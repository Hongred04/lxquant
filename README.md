# lxquant · 大金融中长线

一个只做一件事的工具：**在大盘跌到位时，买 1 家银行 + 1 家保险，拿 40 天。**

打开就是一块屏：

```
┌ 进场信号 ──────────┬ 净值曲线（19 年，可悬停）──────┐
│ 20日线 -2.68% 需-2  │ 年化 4.2%  回撤 -36.8%  夏普 .29│
│ 年线   -9.38% 需-8  ├ 每年赚多少（柱状图）─────────┤
│ ● 可以买            │ 历史机会（33 次，逐次明细）───┤
├ 今天买这两只 ──────┤                                 │
│ 浙商银行 / 新华保险  │                                 │
├ 我的持仓（第 N/40 天）┤                                 │
└────────────────────┴─────────────────────────────────┘
```

## 规则

| | |
|---|---|
| 进场 | 上证相对 20 日均线跌幅 > 2%，**且**相对年线（MA250）跌幅 > 8% |
| 选股 | 银行里避差分最高的 1 只 + 保险里最高的 1 只 |
| 卖出 | 40 个交易日到期，或任一只跌破买入价 8% 先卖 |
| 仓位 | 各一半 |

参数写死在 `lxquant/finance.py`，界面不给调 —— 给的旋钮越多，越容易用调出来的参数骗自己。

## 成绩（2007-03 ~ 2026-11，19.7 年，后复权）

| 年化 | 最大回撤 | 夏普 | 卡玛 | 交易 |
|---|---|---|---|---|
| **+4.2%** | **−36.8%** | **0.29**（±0.23） | **0.12** | 32 次 |

分年度：2007 +1% / 2008 **−27%** / 2009 +22% / 2010 +9% / 2011 +3% / 2012 +26% /
2013 −1% / 2014 −4% / 2015 +19% / 2016 −5% / 2017 +1% / 2018 −0% / 2019 +12% /
2020 +4% / 2021 +1% / 2022 −1% / 2023 +3% / 2024 **+30%** / 2025 +1% / 2026 +3%

**20 年 14 正 6 负**，最大亏损年 2008（−27%）。回撤 −36.8% 也全部来自那一年，
2010 年之后的最大回撤是 −17.9%。

历史机会：**33 次、32 次已结算、21 胜、平均 +2.67%/次**（同期上证 +1.38%）。
净值曲线和机会清单出自同一个日频回放引擎（`tools/backtest_fin.py`），
所以「年化」和「每笔平均」一定对得上，不再是两个脚本各算各的。

> **为什么从 10 年改成 19 年。** 10.8 年的样本（2016-2026）刚好躲开了 2008 和 2015，
> 回撤算出来 −39.9%；换成 2007 年起的 19 年后，同一套规则是 −57.3%。
> 更长的样本还暴露了一个数据问题：腾讯/东财的**前复权**在长历史高分红股上会算出
> **负价格**（招商银行 2016 年前复权价 −0.16 元），负价和 0.2 元的报价让「相邻两日比值」
> 也不可信 —— 所以整条链路换成了**后复权**。
> 加了「大盘跌破年线 8% 才买」这个条件之后（见下），回撤从 −57.3% 回到 −36.8%。

## 已知偏差（都写在明处）

1. **回测池子只含当前还在交易的票。** 2007 年以来退市的银行/保险拿不到，而退市股
   通常暴跌 —— 所以 +4.2% 是**高估**的。
2. **样本 19.7 年、32 次交易。** 一年 1.6 次，统计上仍然薄：夏普 0.29 的标准误是 0.23，
   换句话说「真实夏普可能在 0.06~0.52 之间」。−36.8% 的回撤是真实可能发生的。
3. **后复权是事后视角。** 分红送转按今天的复权因子回算，实盘会有现金分红和除权跳空。
4. **到期日按工作日推算，不含法定节假日。** 真实到期可能顺延一两天。
5. **复权价不能当成交价看。** 后复权下中国平安 2007 年是几十元、今天是几千元，
   差的是 19 年的分红送转，不是涨了 100 倍。**只有相邻两日的比值有意义**。
   （前复权更糟：长历史高分红股会算出负价，招行 2016 年就是 −0.16 元，那时连比值都不可信。）
6. **盘中打开看到的是昨收的信号。** 收盘价才是决策基准，15:10 之后才切到当天 ——
   不然信号会随盘中价格漂移，同一句话两小时后自我否定。

## 目录

| 路径 | 是什么 |
| --- | --- |
| `run.py` | 启动入口（HTTP 服务） |
| `lxquant/finance.py` | **唯一在用的策略**：择时 + 选股 + 落盘 |
| `lxquant/fin_pos.py` | 持仓跟踪：买了没 / 第几天 / 还剩几天 / 浮盈亏 |
| `web/` | 前端：纯 HTML/CSS/JS，无框架、无依赖；**改了要构建**，见下 |
| `data/` | 配置与运行数据（行情缓存 `data/cache/` 不进库，会自动重下） |
| `runtime/` | 自带的 Python 运行时，不进库 |
| `tools/` | `build.js` 压缩前端；`check.py` 一键自检 |
| `tests/` | 纯标准库单测，`runtime/python.exe -m tests.run` |
| `AGENTS.md` | 给 AI / 接手的开发约定和已知的坑 |

## 接口

| 路径 | 说明 |
|---|---|
| `GET /api/fin` | 当前信号、两只票（含因子明细）、市场状态 |
| `GET /api/fin/history` | 10 年净值曲线 + 分年度 + 指标（离线算好存盘） |
| `GET /api/fin/trades` | 39 次历史机会明细（离线算好存盘） |
| `GET/POST /api/fin/pos` | 持仓：`{action:"open"|"close"}` |
| `POST /api/fin/refresh` | 强制重算（刷新按钮走这个） |

`history` 和 `trades` 都是离线脚本生成的，不在请求里跑 —— 算一次要读 1 GB 长表：

```
runtime/python.exe ../factor_lab/71_dump_history.py    # 净值曲线
runtime/python.exe ../factor_lab/70_dump_trades.py     # 机会清单
```

## 不进的目录

`data/cache/`（500MB+ 行情缓存，删了自动重下）、`data/export/`、`runtime/`、
`data/long_all.pkl`（1 GB 长表）、`data/fin_state.json`（运行缓存）。

## 改完代码怎么验证

```
./runtime/python.exe tools/check.py
```

语法、单测、前端语法、构建新鲜度一次查完。

**改了 `web/app.js` 或 `web/style.css` 必须重建**：

```
node tools/build.js
```

原因：服务端 `_static()` 看到同名 `.min` 就**优先发压缩版**。只改源文件不重建，
刷新看到的是旧代码 —— 这个坑很容易误判成「改了没用」。调试用 `?raw=1` 看源码版。

## 开发约定

改之前先看 **[AGENTS.md](AGENTS.md)**：数据口径（`d_` 不复权 / `dl_` 前复权）、
界面硬规则（禁止 `justify-content:center`、一屏验收标准）、外部接口的坑都在里面。

研究过程在 `docs/因子研究-2026-11.md` 和 `docs/策略验证记录.md`。
「大金融中长线」这个方向的外部调研（GitHub 三个项目 + 券商研报）和本地复现，
见 **[docs/大金融策略调研-2026-11.md](docs/大金融策略调研-2026-11.md)** ——
结论是：择时这一环有效（+3 个点收益 / −26 个点回撤），
但「选便宜还是选强势」在两段样本里完全反转，没有跨时代的稳定 alpha。
