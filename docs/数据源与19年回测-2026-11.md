# 数据源换血：从 10.8 年前复权，换成 19.7 年后复权（2026-11）

> 结论先说：
> 1. 能白嫖到的最长 A 股日线是**腾讯**，按两年一段往回翻可以到上市首日（平安银行 1991）；
> 2. 但**前复权不能用**——长历史高分红股会算出负价格，负价让「相邻两日比值」也不可信；
> 3. 换成后复权 + 19 年样本之后，原来那套「弱市买 1 银行 + 1 保险」的最大回撤
>    从 −39.9% 变成 **−57.3%**，全部发生在 2008；
> 4. 补一条「大盘跌破年线 8% 才买」之后，19 年年化 **+4.2%**、回撤 **−36.8%**，
>    2010 年以后是 **+5.0% / −17.9%**。

## 一、为什么换

界面上的成绩一直标着「10.8 年、45 次交易、回撤 −39.9%」。这个样本有两个问题：

- **窗口刚好躲开两轮股灾**：2016-01 起算，2008 和 2015 都不在里面。
- **前复权在高分红股上是坏的**：不是"略有失真"，是会算出负数。

第二点是在换数据源时顺手查出来的，下面第五节有实测。

## 二、GitHub 上找到的做法

`akshare`（18k star，`akfamily/akshare`）的 `akshare/stock/quote/stock_hist_tx.py`
是这次唯一有用的参考。它拉腾讯历史行情的核心就三行：

```python
_TX_YEARS_PER_REQUEST = 2        # 两年约 490 个交易日，低于单次 640 条上限
url = "https://proxy.finance.qq.com/ifzqgtimg/appstock/app/newfqkline/get"
param = f"{symbol},day,{year}-01-01,{year+1}-12-31,640,{adjust}"
for year in range(start.year, end_year, _TX_YEARS_PER_REQUEST):
    ...
```

关键信息是 **`param` 里的日期区间**。本项目原来的腾讯接口只写
`param=sh601398,day,,,640,qfq`（"最近 640 根"），所以永远只有 2.6 年 ——
不是数据源不够长，是请求写法没用上。

为什么不用 `akshare` 本身：它是几百个接口 + requests + pandas 的合集，装进
`runtime/` 会污染这个 100MB 的裸 Python；而这个项目只需要一个 GET。

为什么不用 `baostock`：免费、2006 年起、接口干净，但走的是自有 TCP 协议
（不是 HTTP），要 vendor 半个客户端；而且之前踩过它返回损坏数据。
`tushare` 要 token 和积分。网易 `quotes.money.163.com/service/chddata.html`
本来是最省事的（直接给 CSV 全历史），本机实测 **502**，和 AGENTS 里记的一致。

## 三、实测能拉多深

```
sz000001 1991-01-02 起 640 根       → 1991-07-10 ~ 1993-12-31  ✓
sh600000 1999-01-01 起              → 1999-11-10（上市首日）~
sh601318 2007-01-01 起              → 2007-03-01（上市首日）~
```

81 只大金融（银行 38 + 保险 5 + 券商 34 + 期货 4）全量拉一遍：**58 秒、275,532 行**，
落盘 2.7 MB。脚本 `tools/fetch_fin.py`，8 线程、失败重试、断点续跑。

## 四、坑：hfq 请求会被 WAF 挡，换域名才行

同一路径下：

| 域名 | `qfq` | `hfq` |
| --- | --- | --- |
| `ifzq.gtimg.cn` | 200 | **501**（HTML 跳 `waf.tencent.com/501page.html`） |
| `web.ifzq.gtimg.cn` | 200 | **501** |
| `proxy.finance.qq.com/ifzqgtimg` | 200 | **200** |

这就是 AGENTS 里那条「腾讯 fqkline 会整片 501」的真身：不是接口挂了，是 WAF 按参数拦。
脚本里三个域名按 `proxy` 优先轮询。

## 五、坑（更贵）：前复权会算出负价格

用 `qfq` 拉完第一次跑回测，净值直接变成负数，年度收益出现 −152%、−2000%。
查下去是价格本身为负：

```
code      min close   负价行数
600036     -13.79      2861
601318     -13.52      1114
000001      -3.62      3355
...
合计 26,701 行负价
```

原因不复杂：前复权是「从今天往回减掉历次分红」，银行股二十年分掉的钱早就超过
1991 年的股价，减成负数天经地义。

**更要命的是东财那份旧数据也有同样的问题**——`data/long_all.pkl` 里招商银行
2016 年的前复权价是 **−0.16 元**，2016-02 那几天甚至是 0.24 元。0.24 元的报价、
0.01 元的最小变动单位，意味着单日收益的量化误差能到 4%。之前「相邻两日的比值是准的」
这个说法，在价格趋近 0 的时候不成立。

所以整条链路改成 **后复权（hfq）**：从上市首日往后乘，永远为正，比值严格保持。
代价是绝对价格没有意义（平安银行今天 2337 元），但回测只用比值。

## 六、两个源交叉验证

同一批 81 只票、同一段重叠期，用「日收益」比对（复权基准不同，只能比比值）：

| 指标 | 值 |
| --- | --- |
| 相关系数 均值 | **0.99982** |
| 最差一只 | 0.9857（601916 浙商银行，2019 年才上市，重叠期短） |
| 日收益差的 99 分位 | **0.077%** |

腾讯后复权 vs 东财前复权，在比值层面是同一个东西。这说明换源不会改变历史结论的方向，
只会修正被负价污染的那部分。

## 七、19 年跑下来，原规则站不住

样本 2007-03 ~ 2026-11（起点由保险上市决定），43 只（银行 38 + 保险 5），
日频回放、往返成本 0.35%、空仓计息 1.2%。

| 规则 | 年化 | 最大回撤 | 夏普 | 交易 |
| --- | --- | --- | --- | --- |
| 只看 vs20 < −2%（原规则） | +3.1% | **−57.3%** | 0.15 | 84 |
| 加：vs250 < −8% | **+4.2%** | **−36.8%** | 0.29 | 32 |
| 加：vs250 < −10% | +3.9% | −36.8% | 0.28 | 27 |
| 加：vs250 < −12% | +4.1% | −36.8% | 0.32 | 24 |

原规则的 −57.3% **全部发生在 2007-10-31 → 2008-09-18 这一段**（220 个交易日），
而且这期间 99% 的时间是满仓的 —— 它不是被一笔交易打穿，是在崩盘里反复进场、
反复被 −8% 止损打出来、然后再进。止损限制的是单笔亏损，不是连续亏损。

顺手试过但**没用**的：

| 想法 | 结果 |
| --- | --- |
| 只在年线之上买（趋势过滤） | 年化 0.0%，回撤 −31.8%：躲开了崩盘也躲开了全部收益 |
| 60 日跌幅 < 12% 才买 | +0.7%，回撤 −58.7%：几乎没区别 |
| 连亏 2 笔停 20 天 | +1.5%，回撤 −70.3%：更差 |
| 账户回撤 8% 就刹车 | +2.7%，回撤 **−16.6%**，但只剩 17 笔；12%/20% 档反而更差，不单调，判为过拟合，没采用 |

阈值 −8 / −10 / −12 三档年化都在 4.1~4.2%、回撤都是 −36.8%，是个**平台**不是刀尖，
所以取 −8（最宽松、交易最多）。

## 八、改完之后的成绩

| | 原（10.8 年，前复权） | 现（19.7 年，后复权，两条件） |
| --- | --- | --- |
| 年化 | +5.7% | **+4.2%** |
| 最大回撤 | −39.9% | **−36.8%** |
| 夏普 | 0.27 | **0.29**（±0.23） |
| 交易 | 45 | 32 |
| 最差单笔 | −16.8% | −15.0% |
| 2010 年后回撤 | — | **−17.9%** |

20 年里 14 正 6 负，唯一的大亏是 2008（−27%）。

## 九、复现

```
./runtime/python.exe tools/fetch_fin.py      # 拉全历史 → data/fin_long.pkl（58 秒）
./runtime/python.exe tools/backtest_fin.py   # 重算净值曲线 + 机会表 → data/fin_*.json
```

两个脚本都只依赖标准库 + pandas，不需要 token，不需要注册。
`data/fin_long.pkl` 不进仓库（2.7 MB，随时可重建）。
